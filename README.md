# Sub Del's Vinyl Vault — веб-версія на Supabase

Це самостійний сайт (React + Vite), підключений до вашої бази Supabase.
Дані зберігаються в реальній хмарній базі — відкривайте з будь-якого пристрою
(телефон, ноутбук, чужий комп'ютер) і бачитимете те саме, з живою синхронізацією.

## Що змінилось порівняно з версією в Claude

- ✅ Дані живуть у Supabase (Postgres) — не в Claude.
- ✅ Фото (обкладинки, платівки) завантажуються в Supabase Storage (bucket `covers`).
- ✅ Живе оновлення між вкладками/пристроями через Supabase Realtime.
- ❌ Прибрано 3 кнопки, що працювали тільки всередині Claude (бо вони викликали
  Anthropic API напряму, а це працює лише в артефактах Claude):
  - "More info" (пошук історії альбому)
  - "Auto-fill from the web" для Label/Genre
  - "Auto-fill from the web" для Tracklist
  Усі відповідні поля залишились — просто заповнюються вручну.
  Якщо захочете повернути ці функції на реальному сайті, знадобиться власний
  Anthropic API-ключ і маленька серверна функція-проксі (можемо зробити пізніше).

## Локальний запуск (опційно, для перевірки)

```bash
npm install
npm run dev
```

Відкриється на http://localhost:5173

## Деплой на Render (рекомендовано)

1. Створіть новий репозиторій на GitHub і залийте туди весь цей проєкт
   (без папки `node_modules` — вона згенерується сама).
2. На render.com натисніть **New +** → **Static Site**.
3. Підключіть щойно створений GitHub-репозиторій.
4. Заповніть:
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist`
5. Натисніть **Create Static Site**.
6. Через 1-2 хвилини отримаєте постійне посилання виду
   `https://your-app-name.onrender.com` — саме його можна надсилати друзям.

## Альтернатива: Vercel або Netlify

Обидва так само безкоштовні для статичних сайтів і працюють ідентично:
- Підключаєте GitHub-репозиторій
- Build command: `npm run build`
- Output directory: `dist`

## Важливо про доступ на запис

Зараз будь-хто з посиланням технічно може додавати/редагувати записи
(через публічний anon-ключ, без повноцінного логіну). Для персонального
хобі-проєкту це прийнятний компроміс. Якщо захочете, щоб редагувати могли
тільки ви — можемо додати просту Supabase Auth (email+пароль) окремим кроком.
